# Pigeon Fountain Balance

一个轻量级、搞笑向的手机网页小游戏草稿。

## 灵感来源

灵感来自一个真实短视频：

一只鸽子发现地面上的小喷泉正在喷水，然后直接把屁股坐在喷水口上，看起来像是在享受一个天然“水疗座椅”。

这个项目不打算复刻原视频，而是抽取其中最有趣的行为：

**鸽子坐在喷水口上，并努力保持平衡。**

## 核心玩法

玩家控制一只已经坐在喷泉水柱上的鸽子。

喷泉水压会不断变化，鸽子的身体会左右倾斜。

玩家需要通过左右操作调整鸽子的重心，尽可能长时间保持平衡。

如果倾斜角度超过安全范围，鸽子就会被水柱弹飞，游戏结束。

基本循环：

坐稳  
→ 水压变化  
→ 调整重心  
→ 越来越难  
→ 鸽子被弹飞  
→ 根据坚持时间结算  
→ 再来一局

## 第一版 MVP

第一版只做一个场景，不做复杂关卡。

需要实现：

- 一只简化的鸽子
- 一个地面喷泉
- 水柱动画
- 左右重心控制
- 鸽子倾斜效果
- 动态水压
- 随时间增加难度
- 坚持时间计分
- 失败后弹飞动画
- 结果页面
- 重新开始
- 手机触摸控制
- 桌面键盘控制

## 游戏风格

方向：

- 轻松
- 荒诞
- 搞笑
- 简洁
- 适合手机竖屏
- 一局约 20～60 秒

不追求真实模拟。

游戏反馈和趣味性优先于物理真实性。

## 结算示例

根据坚持时间给予不同称号，例如：

- 0–3 秒：第一次坐
- 3–8 秒：有点舒服
- 8–15 秒：喷泉熟客
- 15–30 秒：鸽子水疗师
- 30 秒以上：城市喷泉之王

具体文案后续可以调整。

## 技术方向

建议第一版使用：

- TypeScript
- Phaser 3
- Vite

暂时不需要：

- 登录系统
- 数据库
- 排行榜
- 微信接口
- 广告
- 后端服务器

## 当前目标

先让 Codex 做一个可以运行、可以玩的草稿。

重点验证：

**“控制鸽子在不断变化的水柱上保持平衡”这件事情本身是否好玩。**

如果核心玩法成立，再继续扩展动画、音效、随机事件、称号和更多场景。
